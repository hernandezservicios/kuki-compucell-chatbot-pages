# Kuki CompuCell — Consulta de Inventario

Frontend público del chatbot de consulta de inventario de Kuki CompuCell,
publicado mediante GitHub Pages. Consulta productos, precios y
disponibilidad en tiempo real.

Este repositorio contiene únicamente el sitio estático (`frontend/`) y
el flujo de publicación (`.github/workflows/`). El backend (Google Apps
Script, la integración con Google Sheets y OpenRouter) vive en un
repositorio privado aparte.
